## 2. 一句话任务与符号

任务是**在结构化地形中逐时刻重建机器人附近的局部三维场景**，不是学习行走控制策略、预测下一帧相机图像，或一次性建立世界坐标系下的全局地图。

定义 `M_t` 为时刻 `t` 四方向深度观测合成的机器人局部测量点云；`P_hat_(t-1)` 是上一时刻网络**预测**的局部场景点云；`T_(t-1→t)` 是根据相邻机器人位姿得到的历史点云到当前局部帧变换；`P*_t` 是同一当前局部区域内的地形真值点云；`P_hat_t` 是输出。期望关系：

```text
P_hat_t = F(M_t, T_(t-1→t)(P_hat_(t-1)))
```

初始时刻没有上一预测，须明示空历史的处理；这是合理的实现契约草案，不是作者公开的初始化代码。当前观测 `k=0`、变换后的上一预测 `k=1`；后续 Stage 2/5 才确定转换细节。输出供下游 locomotion controller 查询地形高度；本项目的重建任务与完整闭环控制实验分开。

## 3. 输入/输出和不能混淆的对象

| 对象 | 生产方 -> 消费方 | 本阶段强制区别 |
|---|---|---|
| `M_t` | 深度相机 -> 表示/模型 | 有遮挡与盲区；绝不能用真值替代测量 |
| `P_hat_(t-1)` | 上一预测 -> 当前模型 | 不能替换成上一帧真值；训练是否停止跨时间梯度在 Stage 4/5 验证 |
| `T_(t-1→t)` | 位姿来源 -> 历史对齐 | 输入估计位姿、真值位姿与噪声版本必须分别命名并记录 |
| `P*_t` | 地形 mesh/实测地图 -> loss/评估 | 仅监督和评分，不得进入推理时模型输入或剪枝保护 |
| `P_hat_t` | 模型 -> 输出/下一时刻 | 3D 点云，不是高度图；高度是可能的下游查询 |

局部地图空间为 3.2 m 每边、64 个体素每边（0.05 m/cell）。**地图原点、轴方向、姿态完整参数化、点云裁剪边界及位姿噪声口径未由论文完整指定**，后续阶段必须给出坐标图、数值例子和测试，不能直接把旧仓库选择当论文事实。

## 4. 两层复现目标，先定义比较域

1. **方法与独立仿真验证**：复刻公开的场景表示、时序反馈、稀疏网络、训练目标和协议；基于独立场景做 P/R/F1、高度误差及机制实验。IsaacLab 替代 IsaacGym 时显式标为偏差，不把本地 F1 与 Table I 同列判优。
2. **真实机器人/论文 Table I**：需相应的 Stairs/Box 数据、四相机、BLK2GO 地图和 ICP、Elevation Mapping/Voxblox、公平输出采样及推理硬件/部署条件。没有这些证据只能报告第 1 层，不能宣称数值复现。

用户已确认 `D-SCOPE-001`：**第一阶段必达目标是第 1 层的可审计仿真方法复现**。第 2 层是后续独立目标，不作为本阶段验收条件；这不等于批准任何具体仿真指标或实现口径。论文限于 structured urban terrain，不把 unstructured rough terrain、动态障碍或完整控制闭环纳入第 1 层通过条件。

## 5. 最终目标与必须完成的工作

本规定的最终对象是**可重跑、可审计的仿真重建方法**：给定结构化地形的四路深度观测与轨迹位姿，逐时刻输出机器人附近局部三维点云；在看不见地形的区域利用空间先验与过去预测，准确重建的同时避免虚构地形。目标不是单个好看的 F1，也不是本阶段完成真实机器人的数值复现。

| 模块（责任阶段） | 必须做的事情 | 验收证据与失败条件 |
|---|---|---|
| 数据（1） | 构建五类地形；四方向向下 30° 的模拟深度相机；采集时序测量、每帧 mesh GT、机器人位姿；记录场景参数、相机内外参、数据版本、采样数量及 train/val/test 场景隔离 | 采集命令、样本 schema、每类场景样例图、统计表、泄漏检查；缺 GT 或同一场景跨 split 则失败。20 万时步是论文数据规模参照，不允许用小样本宣称数据规模复现 |
| 表示与网络（2–3） | 3.2 m/64³ 稀疏网格，体素重心与子体素特征；4D 空时稀疏 U-Net、4 次下采样/上采样、skip、4 级 pruning、3D 输出特征；逐层对照 Fig.2 22 个卷积类操作 | 单元测试、形状/稀疏占用日志、Fig.2 层级对照与明确偏差表；不能以普通 3D 网络或不同拓扑冒充论文结构 |
| 训练与增强（4、6） | target occupancy 多尺度 BCE + 子体素距离；阈值 α=0.5 的主实验；长度 12 的 rollout 每步监督；Adam、论文 LR 起止值；论文列出的几类数据增强分别验证 | 配置、loss 分项、短训练检查、checkpoint 与完整训练日志；无损失下降之外的输出检验或缺少任何关键分项，不算完成 |
| 时序反馈（5） | 上帧**预测**按相对位姿对齐并与当前测量作为不同时间坐标输入；明确空历史及跨时梯度边界；验证推理不使用历史 GT | 坐标变换数值例、首帧/连续帧测试、可见→盲区同物体的配对轨迹图；使用历史 GT、目标泄漏或坐标错位则失败 |
| 评估与审计（7–8） | 固定版本的留出场景，同一测量/GT 上评估原始测量、仅当前帧、完整方法；复做空间补全、历史记忆、0–80% 测量删点和 α 灵敏度；提供失败例 | 同配置评估命令、逐帧原始输出与汇总表、图、资源和失败日志；只展示精选画面、只报训练集或混用评估协议则失败 |

各阶段未公开细节单独批准并标注 `IMPLEMENTATION_ASSUMPTION`，替代仿真器/相机/策略也必须明示偏差。20 万时步、论文硬件与作者未公开数据不可被悄悄降为“已严格复现”；资源不足时可分为**机制验证**与**完整规模运行**两种状态，不以少量样本替代后者。

## 6. 指标、对照和通过规则

| 类别 | 必须报告/对照 | 用途与不得做的比较 |
|---|---|---|
| 主重建质量 | robot-centric 64³、每格 0.05 m 上的 Precision、Recall、F1（%）；分地形、分场景与总体 | 与**同一仿真留出集**的原始测量和仅当前帧比较；报告差值与波动，不把 Table I 当作仿真绝对阈值 |
| 地形高度 | 重建相对 GT 的 height MAE（cm）；同时报 XY 有效覆盖、无预测比例 | 高度匹配与空列处理须在正式评估前批准；不可只在预测存在的 XY 上报很低 MAE 而隐藏缺失区域 |
| 机制与鲁棒性 | 相同轨迹的单帧/反馈成对 P/R/F1/MAE；可见→盲区的追踪样例；测量删点率 0、10、20、30、40、50、60、70、80% 的曲线及空张量次数；α 扫描的 P/R/密度 | Fig.4/5/6 为**趋势与机制对照**。论文 50% 删点 F1≈88% 是参照点，不能不匹配数据/删点协议就设为硬门槛；>80% 可另做失败诊断 |
| 数据、计算与可重复性 | 各类场景/轨迹/帧数、测量点数、GT 点数、可见率本地定义、模型参数/非空体素数、训练步数和处理帧数、推理耗时及硬件、至少重复种子与差异 | 论文 20 万时步、43% 可见率和 70ms/6Hz 是规模/实机参照；本地数值不同需解释，不可称同口径失败或成功 |
| 论文真实机器人 Table I | Stairs Ours 86.0/89.9/88.9、0.8cm；Box Ours 84.8/84.9/84.8、1.0cm（P/R/F1/MAE） | 仅列于**论文参照**，不纳入本阶段通过条件；缺 BLK2GO/ICP 同域真值不能计算“达到论文的百分比” |

本阶段**不虚构 F1≥X 或 MAE≤Y 的论文级通过线**。正式验收分四档：`未运行`、`可运行/机制未证实`、`仿真方法复现通过`、`含论文规模与协议的扩展验证`。其中“仿真方法复现通过”需上表五模块证据齐全、独立留出集可重跑、无数据泄漏、主指标/高度/覆盖与空输出完整报告、反馈与单帧对照以及删点曲线完成，并对未达到预期的机制如实标 `未证实`；**不能因 F1 单项高就自动通过**。具体数值差异与其置信/波动、失败案例必须提交用户审查，关键机制未证实则只能处于第二档。要宣称“超过 baseline”，必须使用同域同协议并报告正向差异和重复种子波动；具体统计判据在 Stage 7 预先批准。本段分层定义已获用户认可，但具体指标实现尚未批准。

每条实验记录最少包含：研究问题、原文锚点、数据/scene seeds、采集 schema 与仿真器、代码 commit、模型配置、训练更新次数/帧呈现量、checkpoint、评估命令、指标协议、随机种子、P/R/F1/MAE/coverage、空输出数、与 baseline 差值、原始日志和失败原因。`retry` 实测与旧仓库历史结果必须分栏。
